# AFTERLIGHT

An original open-world first-person survival/action game built in Godot 4.x.

**Current build: Phase 1 — Player movement test zone.**

## How to play

1. Open the project in Godot 4.x (`project.godot`)
2. Press **F5**

## Controls

| Key | Action |
|---|---|
| W A S D | Move |
| Mouse | Look |
| Shift (hold) | Sprint (drains stamina) |
| Space | Jump |
| Ctrl (hold) | Crouch |
| Sprint + tap Ctrl | Slide |
| E | Interact (doors, switches) |
| Esc | Free the mouse |

## The test zone

Follow the floating signs: sprint lane, crouch tunnel, slide bar, jump gaps,
stairs to a two-story building with a sliding door, a light switch inside,
and a rooftop.
